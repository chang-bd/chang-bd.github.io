# 《攻城象棋》官方规则书

**定稿最终版 · 含完整叙事标注**


## 一、游戏背景

> 红方是**攻城军**，趁夜色突袭敌城。三路冲车（俥）直抵城门，四队骑兵（马）两翼包抄，三门火炮（砲）在阵后架起。全军无大营（帅）、无辎重（仕象），皆为战兵，有进无退。
>
> 黑方是**守城军**，被突袭惊醒，仓促登城应战。城防工事完整（士象全），守将坐镇九宫，弓弩（砲）架于城楼，步兵（卒）列阵墙头。据城而守，退无可退。
>
> **红方胜 ＝ 破城擒王**（将死/困毙黑将）  
> **黑方胜 ＝ 攻城军溃退**（红方俥/马损失到临界点，军心涣散）

## 三、走子规则

全部按中国象棋原版：

| 棋子 | 走法 | 特殊限制 |
|------|------|----------|
| 俥/车 | 横竖直线任意步，遇子可吃 | 无 |
| 马 | 走“日”字 | **有蹩马腿** |
| 砲 | 走直线（同俥），吃子**隔且仅隔1个** | 双方砲规则完全相同 |
| 兵/卒 | 过河前只能前进，过河后可横走 | 不能后退 |
| 象 | 走“田”字 | **有塞象眼** |
| 士 | 九宫格内斜走一步 | 无 |
| 将 | 九宫格内横竖走一步 | 无 |

### 红方无帅（核心逻辑）

- 红方棋盘上**没有帅**，因此：
  - “将军”、“应将”、“将帅对面”等概念对红方**完全不适用**。
  - 黑方**无法**对红方“将军”。
  - 红方棋子**不受九宫格限制**，可自由出入。
  - 红方棋子在九宫格内**不会**与黑将形成“对面”关系（因为红方无帅）。

### 双方砲规则

- 双方砲**完全相同**：走直线，吃子隔且仅隔1个，吃后留在原位。
- 区别仅在于红方3门、黑方2门。


## 四、红方获胜条件

| 编号 | 胜利条件 | 叙事映射 |
|------|----------|----------|
| ① | **将死**：红方走完后，黑方将被将军且无法应将 | 破城擒王 |
| ② | **困毙**：轮到黑方走时，黑方将未被将军，但黑方所有棋子均无合法走子 | 守军被围死，弹尽粮绝 |


## 五、黑方获胜条件

> **叙事逻辑**：红方没有帅，黑方无法通过“将死”红方获胜。黑方只需**摧毁攻城军主力部队**，使其丧失攻城能力，**军心涣散，自行溃退**。

黑方通过吃子，**累计**达成以下任一条件，**立即获胜**：

| 编号 | 胜利条件 | 说明 | 叙事映射 |
|------|----------|------|----------|
| ① | 吃掉红方全部 **3个俥** | 俥被吃光 | 冲车全毁，破门无望，士气崩溃 |
| ② | 吃掉红方全部 **4个马** | 马被吃光 | 骑兵全灭，机动兵力归零，军心动摇 |
| ③ | 吃掉 **俥×2 + 马×3** | 共5个近战大子 | 车骑损失过半，建制被打残，士兵自行溃退 |

> **红方砲不计入黑方胜利条件。** 砲是机械装备，摧毁砲只削弱火力，不影响军心。


## 六、禁吃卒（城墙保护）

> **叙事映射**：黑方卒列阵城墙之上，受城防工事掩护，红方近战部队无法直接攻击。

- 若黑方某个卒在本局游戏中**从未被黑方移动过**（即仍在初始位置），则：
  - 红方**俥、马、兵**均不能吃这个卒。
  - 只有红方**砲**可以吃这个卒（远程火力可越过城墙）。
- 一旦该卒被黑方**主动移动过**（任何一步），保护立即失效，红方任何棋子均可正常吃它。


## 七、前线限制（补给限制）

> **叙事映射**：红方是长途奔袭的攻城军，深入敌境作战，补给线脆弱。每个士兵（俥/马/兵）都需要携带干粮、箭矢、草料，超过4个单位的兵力深入敌阵，补给就跟不上了。
>
> 砲是**机械装备**，不需要吃喝，靠畜力或人力拖拽即可，**不计入补给消耗**。

- 红方在**黑方半场（第1行至第5行）**内的非砲棋子总数，**任何时候不得超过4个**。
- 若某一步走完后超限，则该走法**非法**，红方须改走其他着法。
- 红方**砲不计入**此限制。
- **黑方不受此限制**。


## 八、双方优劣势分析

| 维度 | 红方（攻城军） | 黑方（守城军） |
|------|---------------|---------------|
| **核心优势** | 先手突袭、3俥4马火力猛、3砲持续压制、无帅所以无“将军”压力 | 阵容完整、士象护将、消耗取胜 |
| **核心劣势** | 无防御、禁吃卒、补给限4 | 后手、车马少、胜利条件难 |
| **战术核心** | 速攻破城，抢在俥马被吃光前将死黑将 | 防守消耗，拖住红方并逐步摧毁俥马 |
| **叙事核心** | 破城擒王，一鼓作气 | 坚壁清野，耗敌溃退 |
| **胜率** | **≈ 52%** | **≈ 48%** |


## 九、补充规则

| 项目 | 处理方式 |
|------|----------|
| 红方无帅 | 黑方无法将军红方，“将帅对面”不适用 |
| 长将 | 红方不得长将（沿用象棋惯例） |
| 长捉/长拦 | 沿用象棋惯例 |
| 重复局面 | 同一局面出现三次，可申请和棋 |
| 和棋 | 双方均无法达成胜利条件时判和 |
| 黑方吃砲 | 可吃，但不计入黑方胜利条件 |
